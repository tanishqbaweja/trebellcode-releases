# Trebell Code releases

Trebell Code is a coding harness built for verified software-engineering quality per dollar: the same or better results at lower model cost. It runs its own agent, Trebell Native, and drives Codex, Claude Code, OpenCode, Cursor, Grok, Antigravity and Muse Code from one desktop app.

This repository holds Trebell Code's released builds. Download them from [Releases](https://github.com/tanishqbaweja/trebellcode-releases/releases).
